# MATA57 - Questões da Lista

Este repositório contém soluções de exercícios de programação da disciplina MATA57 (Laboratório de Programação). As questões estão organizadas em duas listas, cobrindo diversos tópicos fundamentais de programação em C++.

## 📚 Estrutura do Repositório

O repositório está organizado em duas listas principais:

### Lista 1
1. **Básico** - Conceitos fundamentais de programação
2. **If & Else** - Estruturas condicionais
3. **Loops** - Estruturas de repetição (for, while)
4. **Vetor** - Arrays unidimensionais
5. **Strings** - Manipulação de strings

### Lista 2
1. **Matriz** - Arrays bidimensionais
2. **Ordenação, Busca Binária, String** - Algoritmos de ordenação e busca
3. **Funções** - Modularização de código
4. **Pilha e Fila** - Estruturas de dados

## 🛠️ Tecnologias Utilizadas

- **Linguagem**: C++
- **Compilador**: g++ (recomendado)

## 📂 Organização dos Arquivos

Cada questão possui sua própria pasta contendo:
- Arquivo `.cpp` com a solução implementada
- Arquivo `.pdf` com o enunciado do problema (quando disponível)

Exemplo de estrutura:
```
lista 1/
  1 - Basico/
    questão 1/
      q1.cpp
    questão 2/
      q2.cpp
    ...
  2 - If & Else/
    ...
```

## 🚀 Como Usar

### Compilar um programa
```bash
g++ -o programa arquivo.cpp
```

### Executar o programa
```bash
./programa
```

### Exemplo completo
```bash
# Navegar até a pasta da questão
cd "lista 1/1 - Basico/questão 1"

# Compilar
g++ -o q1 q1.cpp

# Executar
./q1
```
